# Security

Please do not publish credentials, personal audio or private transcripts in issues. Report security-sensitive problems through GitHub's private vulnerability reporting when enabled, or request a private contact route without disclosing exploit details publicly.

Only download installers from this repository's releases and compare their SHA-256 checksums. The initial installer is unsigned; do not interpret a checksum as a digital signature.

Do not commit GitHub tokens, signing certificates, private keys, local settings or model credentials. If a credential has been exposed, revoke it promptly.
